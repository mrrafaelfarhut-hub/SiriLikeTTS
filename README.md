# Siri-like TTS for HONOR Magic8 Pro

Первый прототип приложения для Android: ввод текста, русская озвучка,
регулировка скорости и высоты голоса.

Важно: приложение не содержит и не копирует фирменный голос Siri. Оно
использует установленный на телефоне Android TTS-движок. Качество и
доступные русские голоса зависят от установленного движка.

Для сборки нужен Android Studio с Android SDK и Gradle.
